这次更新带来 **多地图框**与**全新深浅色编辑界面**：可以在同一画面里组合全局路线与局部跟随视图，每个地图框独立调整取景和轨迹样式，同时修复倍速取景、暂停跳转和防抖重新开启等问题。

## 🗺️ 多地图框，一屏组合不同视角

- 同屏添加多个地图框，每框独立选择 **固定分段、跟跑者居中、跑者居中＋分段定向**，分别调整缩放、边距与镜头灵敏度。
- 每框可独立设置路线、尾巴、控制点与运动员的显示、颜色、透明度、线宽及配速色带；时间校准保持全局一致。
- 地图布局编辑器支持 **添加、复制、删除**，以及在预览中选中、拖动、缩放、旋转、吸附和撤销；框标签自动换行，多框时操作按钮也保持可见。

## 🎨 自由地图布局与全新编辑界面

- 地图支持固定左侧、固定右侧或自由叠放；自由框可设置 **圆形、矩形圆角、不透明度与边缘羽化**，预览与导出使用同一套合成。
- 默认采用专业剪辑暗色，同时提供 Fluent 浅色和跟随系统选项；统一控件、图标、字体与选中状态，改善导航和设置面板的可读性。
- 主题作为用户偏好单独保存，打开工程不会改变当前主题；高级选项支持动画展开。
- 视频防抖开关和参数合并到同一卡片，关闭时收起配置并保留已有参数。

## 🎥 取景与倍速回放更准确

- 固定分段按整段轨迹边界取景，包含绕行、折返和原始采样点，减少途中轨迹超出画面的情况；圆形地图框也会将整段轨迹收进圆内。
- 修复倍速播放与导出时镜头跟不上跑者的问题；固定分段的平移、旋转和缩放过渡保持原速，不再随轨迹倍速一起加快。
- 多地图框复用地图遮罩与配速色带缓存，减少重复绘制开销。

## 🛠️ 播放、导出与 Windows 修复

- 预览进度条下沿新增分段标记：点击跳到分段起点，悬停显示分段、点号与时间。
- 修复暂停时重复或近距离跳转不刷新，以及连续前后跳转被旧帧覆盖的问题。
- 修复关闭视频防抖后再次开启误报「无运动数据」。
- 没有源视频的工程直接导出和队列导出使用地图／HUD 时间轴；修复静态地图按 GPX 时间轴导出且关闭 HUD 时无法确定时长的问题。
- 修复 MSIX 安装后，资源管理器中 `.trr` 工程文件图标过小的问题。
- 发布前 **215 项单测通过**（另有 2 项素材测试忽略），并验证多框预览、真实导出像素、无源视频导出与便携包独立启动。

## 📂 工程兼容

- 旧单框工程可直接打开，自动迁移为单框布局；多框布局和逐框样式随 `.trr` 工程保存。
- **多框工程请使用 0.4.0 或更新版本。** 旧版只会显示第一个地图框，用旧版另存会丢失其余框。
