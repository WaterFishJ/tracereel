这次更新主要修复 **QuickRoute 地图导入**与**纯轨迹播放**，同时改善手表轨迹中断时的 HUD 表现，并新增可选的步频数据项。

## 🗺️ QuickRoute 地图导入恢复正常

- 修复 **0.3.0 引入的回归**：导入自带分段的 `.qrt` 时，不再出现「分段进来了，地图却没进来」的问题。
- 工程还没有分段时直接导入；已有分段时仍询问是否覆盖，地图与轨迹会先正常载入。

## ▶️ 没有视频，也能顺畅回放轨迹

- 只导入地图与轨迹时，按路线或 GPX 的时间轴确定播放时长，地图、跑者与 HUD 一起前进。
- 支持倍速播放、暂停拖动、继续播放与末尾循环；拖动进度后不再卡住等待视频帧。
- **地图与 HUD 自动铺满画面**，无需手动取消默认的视频勾选。

## 📊 HUD 新增「步频」

- 支持高驰（COROS）与 Garmin GPX 中的步频记录，显示单位为 **步/分**。
- 可添加为独立数字卡，也可放入经典面板；默认不开启，原有布局保持不变。
- 按文件记录值显示，不自动翻倍；缺失数据或自动补点期间显示 `--`。

## ⌚ 轨迹短时中断，HUD 不再原地冻结

- 手表暂停记录或短时丢失信号后，自动补齐符合条件的时间缺口，让配速、距离与航向继续推进；`.qrt` 自带轨迹同样受益。
- 低速缺口按原地等待处理：速度显示 `0`、配速显示 `--`，避免出现异常大的配速。
- 仅补齐 **不超过 60 秒、推算速度不超过 54 km/h** 的缺口；长时间中断与异常跳变保持原样。

> 补齐的位置、海拔与心率来自相邻记录的插值，用于改善回放连续性；步频不会由插值生成。

## 🧩 其它改进

- 新增关于页，完善 Windows 可执行文件的图标与版本信息。
- 提供 **MSIX 商店包**，补齐隐私政策、许可与对应源码说明。
- GitHub Actions 增加微软商店自动更新流程：完成账号配置后，可将正式版本的 MSIX 提交商店审核，也支持手动上传草稿测试。
- 发布前 **166 项单测通过，统一测试入口的 10 组检查全部通过**，覆盖地图导入、纯轨迹播放、HUD 与实际导出等场景。
