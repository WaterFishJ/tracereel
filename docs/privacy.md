# TraceReel 隐私政策

生效日期：2026-10-22

本政策适用于从微软商店、GitHub 或其他渠道获得的 TraceReel（迹映）Windows 版本。

## 1. 我们不收集任何个人信息

TraceReel 没有账号、没有登录、没有遥测、没有崩溃上报、没有使用统计，也不会在运行时发起网络请求。开发者无法通过本程序获得你的任何个人信息。

## 2. 只在本地处理你选择的文件

程序会读取你主动选择的视频、定向地图、GPS 轨迹（`.gpx`、`.qrt`、`.gpx.jpg`）、成绩单照片等文件，用于预览、防抖、OCR 识别与导出视频。**所有处理都在你的电脑上完成，不会上传到任何服务器。**

导出视频与工程文件（`.trr`）由你选择保存位置，开发者不会获得这些文件。

## 3. 程序在本机保存的设置

为便于下次使用，程序会把设置保存在本机：

- `%APPDATA%\TraceReel`：预设、HUD 模板、导出队列、最近使用的设置；
- `%LOCALAPPDATA%\TraceReel`：导出日志等本地记录；
- 系统临时目录：导出过程中的临时文件，正常结束后会自动清理。

首次运行时会尝试从旧版 OrientView 目录复制用户设置（仅在本机复制，不会上传）。卸载程序时这些目录默认保留，你可以手动删除。

## 4. 第三方组件

程序随包包含 FFmpeg、Qt、ONNX Runtime 与 OCR 模型，它们均在本机运行，不收集或上传数据。各组件的许可见安装目录下的 `licenses/` 目录与仓库中的 [THIRD-PARTY.md](https://github.com/WaterFishJ/tracereel/blob/main/THIRD-PARTY.md)。

## 5. 儿童隐私

本程序不面向儿童收集任何信息，也不包含广告、社交或用户生成内容功能。

## 6. 政策变更

如果本政策发生变更，我们会在本页面更新生效日期；涉及数据处理的重大变化会同时在版本更新记录中说明。

## 7. 联系方式

如有隐私相关问题，请通过 [GitHub Issues](https://github.com/WaterFishJ/tracereel/issues) 联系开发者。
