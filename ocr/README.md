# 本地成绩条 OCR

分段页面 → 从成绩条图片导入 → 选择照片 → 拖动四角框住成绩表 → 选择旋转方向 → 校正并识别。

图片区域支持滚轮缩放（1～8 倍，围绕鼠标位置），放大后可拖动图片平移。四角手柄始终对应原图坐标；点击“适应”恢复全图。原图和校正图均支持缩放。

请使用文字清晰的成绩条照片。识别完成后指定时间列（累计用时或分段用时）、可选的分段号列和点号列。无需固定列顺序。逐格修改识别结果，取消勾选表头、说明及其他无关行。起点累计时间为 0 时不会产生分段；终点作为最后一段。导入沿用选择的时间类型及识别出的时分秒格式，只去除无意义的前导零，例如 `00:22:03.1` → `22:03.1`。照片、识别与校验均在本机完成。

自动识别行列，支持只印累计用时或分段用时、两种时间列顺序互换的成绩条。

时间整理以冒号定位完整的 `时:分:秒` 或 `分:秒`，分、秒不得达到 60，小数秒支持小数点或小数逗号后 1～3 位。已合法的时间不改动，首段数字不强制截为两位，避免误伤 `125:30` 等长用时。秒整数部分多出一位且边界为 `1` 时，将它视为疑似误识别的竖线并生成候选，例如 `00:03:021` → `00:03:02`；不凭空补小数点，也不删除小数位。候选唯一时修正；存在多个合法候选时，只有多行数据已确认累计／分段列关系，且相邻累计时间之差能唯一匹配分段时间，才进一步修正，否则保留原值。自动修正或仍有歧义的时间以橙色提示核对；序号、点号及合法时间中的数字 `1` 不受影响。

选定点号列后，连续同点的记录会高亮为“疑似重复打卡”，不会自动合并。每行末尾有“↑合并”和“↓合并”，任何相邻行均可合并，无需点号相同或指定点号列。合并会直接删除当前行并更新目标行所选时间列：分段用时相加；累计用时保留两行中后一行的时刻，向上合并时因此会更新上行时刻。目标行点号等其他字段保留，可撤销最近一次合并，恢复删除的行及原时间。未选为时间列的其他列不参与计算。输入分段用时模式时，取消勾选的有效时间仍参与累加，保持后续累计时刻与终点不变；如果是误识别出的非打卡数字，应将该时间格清空后取消勾选。

分段页面的手动输入也支持可选点号，留空即可。点号与每个时间一一对应，随工程保存和加载，删除行时一并删除。

使用 PP-OCRv4 mobile 检测、方向分类和识别模型（复用 RapidOCR 1.4.4 分发的 ONNX 模型），Rust 的 `receipt-ocr` 库通过固定版本 `ort 2.0.0-rc.10` / ONNX Runtime 1.22.0 在 CPU 上运行。模型会话常驻，后台线程直接调用，无 Python 子进程。裁剪、旋转、透视校正、检测框后处理、CTC 解码及行列整理均由 Rust 完成，无 OpenCV 运行时。识别时无网络请求，关闭 ONNX Runtime 遥测。自动根据列间空白分区，按检测到的倾斜文字框切分单元格，减少序号/点号/时间黏连。格式、纸张弯曲或图像质量仍可能导致错误，必须核对预览。裁剪四角按左上、右上、右下、左下排列，旋转作用于校正后的图片。

## 开发环境

运行 `ocr/setup.ps1`，下载并校验固定版本的 ONNX Runtime 和模型到 `tools/ocr`。无需安装 Python；脚本仅从校验过的 wheel 压缩包提取三个模型，不安装其中的 Python 代码。首次准备需联网，之后可断网运行。可通过 `TRACEREEL_OCR_DIR` 指定完整运行时目录。Rust 引擎修改后需重新编译应用。

`cargo test -p receipt-ocr` 验证裁剪、旋转、时间分词、空格单元格、竖线误识别容错、小数秒保护、歧义保留及 CTC 解码。真实样图回归分别运行：

- 设置 `TRACEREEL_OCR_SAMPLE` 为原始样图路径，运行 `cargo test --release -p receipt-ocr --test sample sample_receipt_times_and_cached_model_reuse -- --ignored`。
- 设置 `TRACEREEL_OCR_SEPARATOR_SAMPLE` 为黄草湾公园竖线分隔成绩条样图路径，运行 `cargo test --release -p receipt-ocr --test sample pipe_separator_does_not_become_a_seconds_digit -- --ignored`。该测试核对全部 22 行累计／分段时间，并重复识别验证会话复用。

诊断 CLI 使用 JSON stdin/stdout，`cargo run --release -p receipt-ocr -- --benchmark` 对同一请求测量首次和缓存会话识别；GUI 直接调用库，不启动该 CLI。

旧 Python 实现移至 `ocr/reference`，仅保留作算法及结果对照，不参与应用运行或便携包。

## 便携包

`package.ps1` 将 Rust OCR 编译进应用，发布包的 `ocr` 目录仅包含模型、ONNX Runtime DLL、说明及许可证。`ocr/build-runtime.ps1` 保留为 `setup.ps1` 的兼容入口，不再构建 PyInstaller。

运行时包含 RapidOCR/PaddleOCR（Apache-2.0）、ONNX Runtime（MIT）等依赖，发布时随包保留许可证和第三方声明。Rust 校正预览暂存在系统临时目录 `tracereel-ocr`，最多保留最近 10 张 Rust 生成的图片。
