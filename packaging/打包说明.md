双击项目根目录的 `package.cmd` 即可重新编译当前代码、收集运行依赖、生成便携 ZIP 和 SHA256 校验文件。窗口最后会显示结果，按任意键关闭。

输出位置是项目根目录的 `dist`。发送最新的 `TraceReel-版本-windows-x64-时间-portable.zip` 给朋友；朋友完整解压后双击 `TraceReel.exe`。程序版本自动取自 Cargo 配置，每次打包创建独立目录。

构建使用 `target/package-build`，不会覆盖 `target/release` 中正在运行的程序。MSVC x64 运行库自动查找；Qt、FFmpeg 和 libclang 默认沿用本机已有构建环境。

首次遇到旧版迁移过的构建缓存时，脚本会自动清理并重新编译本地 Rust 模块，保留第三方依赖缓存。OCR 源码和发布 ZIP 的 SHA256 使用 .NET 计算，不依赖 `Get-FileHash` 命令。

也可以在 PowerShell 中运行：

```powershell
.\package.ps1
```

如果已经编译好、只需要重新收集依赖和压缩：

```powershell
.\package.ps1 -SkipBuild
```

依赖安装位置改变时，可以传入路径（传入的 Qt 和 FFmpeg 路径同时用于编译和打包）：

```powershell
.\package.ps1 -QtRoot 'C:\Qt\6.8.2\msvc2022_64' -FFmpegDir 'D:\ffmpeg-dev' -CrtDir 'C:\path\to\Microsoft.VC143.CRT'
```

可以用 `LIBCLANG_PATH` 环境变量指定 libclang 目录。缺失构建工具或运行依赖时，脚本报错并停止，不会报告打包成功。

可选的解压验证：

```powershell
.\packaging\verify-package.ps1 -Zip 'D:\path\to\TraceReel-portable.zip'
```
