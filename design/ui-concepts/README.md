# TraceReel 界面视觉概念

这三张图使用 **Qt/QML 实际渲染**，不是网页截图。内容、布局与参数完全相同，只改变配色、层级、圆角、边框和选中状态，便于比较视觉效果。

预览中的地图、路线、跑者与数据均为示意图，不代表真实比赛素材。前四张是选型阶段概念图；05～08 来自真实主窗口。

## 控件形态改造（第二轮）

主窗口配置分区使用带标题、边框和内容留白的卡片；布尔设置使用行尾开关；滑杆采用上方标题与右侧数值框、下方通长轨道。高级选项按最初概念图使用左侧「＋ 高级选项」文字入口，展开后显示「−」，不使用嵌套灰底卡片。平滑参数行按实际父容器取宽度，避免右侧数值及单位被裁切。标签与数值统一为 13px，并检测可用字体，避免首选字体缺失时任意回退。

地图和 HUD 编辑器同步开关与输入框样式。地图的外观、取景和逐框样式滑杆也改为两行布局，保留原有参数换算、连续更新、撤销与设置写回。滑杆手柄在最小值与最大值时保持在控件边界内。

- `renders/07-controls-dark.png`：第二轮改造后的真实视频设置页，专业深色。
- `renders/08-controls-light.png`：同一设置页，Fluent 浅色。

高级选项使用 240ms 高度展开与位移动画、180ms 淡入淡出；正文标签使用 Theme.text，提示、单位和禁用状态各自使用对应语义色。主题偏好独立保存在用户配置目录的 settings.ini 中，工程不保存或读取主题。

验证：GUI 与 qmlprobe 构建成功，210 项单元测试通过；真实 QML 的展开布局、字体及标签颜色在深浅色下通过；保存工程不含主题字段、打开旧工程不改变当前主题、跨进程恢复用户偏好均已验证。

## 方案一：专业剪辑暗色（推荐）

参考 DaVinci Resolve 等专业创作工具的视觉语言。

- 中性石墨色背景，压低界面存在感，让地图与视频成为视觉中心。
- 蓝色只用于当前页签、滑杆、焦点和主要按钮。
- 4～6 像素圆角、细分隔线、较少卡片，信息密度最高。
- 适合长时间编辑，也最适合 TraceReel 的地图、视频和运动数据组合。

## 方案二：Fluent 浅色

参考 Microsoft Fluent 2；Qt Quick Controls 也有 FluentWinUI3 风格可作为后续技术参考。

- 浅灰工作区、白色面板、蓝色强调，接近现代 Windows 桌面软件。
- 卡片分组更明确，输入框边界清楚，第一次使用时更容易理解。
- 不建议硬仿云母或亚克力透明效果；纯色层级在 QML 中更稳定、清晰。
- 浅色主题下，视频预览仍应保持深色，避免影响画面颜色判断。

## 方案三：现代极简

参考 Linear 的产品视觉语言，保留较浓的品牌感。

- 深色底配紫色强调，圆角和选中底色更明显。
- 卡片化最强，视觉更年轻，也更适合展示型产品。
- 相比方案一，装饰和分组占比更高；落地时应控制留白，不能牺牲长参数页的密度。

## 建议

采用 **方案一作为默认深色，方案二作为浅色**；方案三的紫色与部分圆角可以留作品牌变体，不必同时维护三套完整主题。

为了降低改造风险，正式落地时可以先保留当前右侧 500 像素设置栏与五个页签，不照搬概念图新增的左侧导航。优先统一控件和主题令牌，再决定是否调整布局。

必须保留的现有交互：

- 数值参数继续使用「滑杆＋数值框」，拖动和编辑继续即时生效。
- 文件路径继续支持手输、粘贴与末尾浏览按钮。
- 只改 `TSlider` 等控件外观，不改变 `SliderField` 的单位换算、精度、防绑定环和提交逻辑。
- 保留普通修改的防抖应用、结构变化的立即应用，以及预览进度条的定位行为。

## 工程落地注意

当前 `app/src/theme.rs` 主要是明暗两套颜色令牌，QML 中仍有散落的圆角、间距和硬编码颜色。若要正式支持这些风格，建议先补齐：

- 表面层级：窗口、面板、卡片、输入框、弹层。
- 边界状态：分隔线、控件边框、焦点、禁用。
- 语义状态：成功、警告、危险、叠加遮罩。
- 尺寸语义：控件圆角、卡片圆角、面板间距。
- 中文字体：优先 Microsoft YaHei UI，并验证数字、百分号与角度符号的对齐。

深色改造还要检查日志、搜索、确认框和导出队列中的硬编码颜色，不能只替换窗口调色板。

## 文件与复现

- `ConceptShowcase.qml`：三套概念图共用的 QML 源文件。
- `render_concepts.py`：PyQt6 离屏渲染脚本。
- `make_control_comparison.py`：生成右侧控件对比图。
- `renders/01-professional-dark.png`：专业剪辑暗色。
- `renders/02-fluent-light.png`：Fluent 浅色。
- `renders/03-linear-modern.png`：现代极简。
- `renders/04-control-comparison.png`：三套控件并排对比。
- `renders/05-actual-dark.png`：正式实现后的真实主窗口专业深色截图。
- `renders/06-actual-light.png`：正式实现后的真实主窗口 Fluent 浅色截图。

在仓库根目录执行：

```powershell
python design\ui-concepts\render_concepts.py
python design\ui-concepts\make_control_comparison.py
```

用户配置位置：便携版 `%LOCALAPPDATA%\TraceReel\settings.ini`；商店版应用包家族目录下的 `LocalState\settings.ini`。首次创建时迁移旧注册表主题，已有 INI 不再读取注册表，更新某个设置时保留其它键；配置文件不随发布包提供。

视频页的稳定化、预设、镜头标定及其它防抖参数统一放入视频防抖卡片；关闭时只显示启用开关，开启时展开内容并淡入。关闭后配置继续保留，再次开启恢复显示。`app/tests/stabilization_toggle_probe.qml` 覆盖关闭/开启/关闭/再次开启的显隐、占位高度和参数保留回归。
